# Roadmap

## v0.1 — GA4 foundation

- Remote MCP over Streamable HTTP
- Google OAuth account connection
- Encrypted refresh-token storage
- GA4 property discovery
- Generic GA4 reporting
- Ecommerce and landing-page tools
- Docker and Nginx deployment

## v0.2 — Reporting quality

- Metadata validation for dimensions and metrics
- Period comparison tools
- Traffic-source and product-performance tools
- Pagination and normalized tabular outputs
- Automated tests

## v0.3 — Shopify

- Multiple Shopify stores
- Orders, products, customers, and inventory
- Cross-source Shopify and GA4 analysis

## v0.8 — Search Console

- Verified property discovery
- Daily, query, page, country, device, and search-appearance performance
- Search type, freshness, aggregation, filters, and pagination controls
- Read-only OAuth scope and guarded request validation

## Later

- Google Ads
- Meta Ads
- Klaviyo
- Linear write tools with explicit confirmation
